# comedouro-esp

Comedouro automático: firmware do ESP32 (`firmware/`), servidor Fastify + DDD + TDD (`server/`) e PWA (`web/`). Projeto de aprendizado.

Quem faz o quê (detalhes em `docs/mentoria.md`):
- **Servidor e PWA:** o Claude implementa, com TDD, a pedido do usuário (desde 10/11/2026), seguindo o `docs/ROTEIRO-PRODUTO.md`.
- **Firmware:** o usuário escreve, e o Claude é mentor.

Toda tela ou funcionalidade do app (`web/`) segue o guia de UI/UX abaixo. Commits em português, conventional commits com escopo (`feat(server): adicionando …`).
